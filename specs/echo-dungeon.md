## 改修設計（D・未実装）

### 分身による協力戦闘

- 記録対象を移動だけでなく「向きと攻撃の時刻」に拡張する。分身は記録した位置・向き・時刻で攻撃を再現し、別の分身や本体が敵の注意を引ける。
- 操作は移動・攻撃・巻き戻しを基本にする。通常画面のボタンは方向・剣・巻き戻し等のアイコンのみ。キーボード割り当てはゲーム外の任意ヘルプに置く。
- 敵は本体と分身の両方を認識・追跡・攻撃する。壁越しに攻撃しない。攻撃の予備動作に入ったら狙う方向を一定時間固定し、背後へ回る余地を作る。
- 分身には耐久を持たせる。倒された分身はそのループ中の移動・攻撃・スイッチ押下を停止するが、次のループで記録の先頭から復帰する。
- 巻き戻しでは敵の位置・体力・罠の状態も初期化する。倒すまで何度でも攻撃を積み立てる仕様にはせず、同じ10秒内で連携を成立させる。
- 本体が倒れた際には既存分身を維持し、失敗した記録を自動追加しない。記録の作り直し・最後の分身の取り消しを維持する。

### 敵と罠

| 種類 | 見た目・挙動 | 攻略として成立させること |
| --- | --- | --- |
| 盾を持つ敵 | 大きい盾と正面の防御姿勢。前方を警戒し、狙った相手へ予告して攻撃 | 1体を囮にして敵の向きを固定し、別の分身が側面・背後から攻撃 |
| 突進する重い敵 | 幅広い体。構え→進路を示す予告→突進→隙 | 囮の移動記録で進路を誘導し、罠に踏み込ませる |
| 床の罠 | 収納・準備・作動を棘や床の動きで描き分ける。スイッチとの対応を同じ形と色で示す | 別の分身が作動スイッチを押し、囮が誘導した敵を罠で倒す |

数値（耐久、攻撃間隔、敵の速度、予告時間、罠の威力）は実装・検証時に調整する。本人が値を指定したことにはしない。

### ステージと進行

- 既存3部屋の基本パズルとクリア記録を保つ。
- 新しい部屋は「囮＋攻撃」「囮分身＋攻撃分身＋本体の役割」「誘導＋罠」の順に体験できる構成を出発点とする。具体的な部屋数は実装判断。
- 戦闘部屋は敵が残っている間、出口を鎖や光の状態で閉じる。戦闘の勝利と出口開放を演出で伝える。
- 既存のスイッチ保持だけでも、囮だけでも、目的の連携をすり抜けてクリアできてしまわないか検証する。

### 通常画面の文字撤去

| v0.1の表示 | 変更方針 |
| --- | --- |
| タイトル、MINIGAME 1GO、PROTOTYPE、キャッチコピー、フッター | 通常画面から撤去。ブラウザのページ名など画面外のメタデータは維持可 |
| CHAMBER、ステージ名、LOOP、部屋番号 | 常設文字を撤去。現在の部屋は点や簡単な地図で示す |
| 残り時間の説明、REC、SEC、数値タイマー | 減っていく円形または棒状のゲージ、終盤の点滅・音 |
| あなた／分身／スイッチ／出口の凡例 | 本体と分身の形・輪郭・透明感・動き、光る出口で直接伝える |
| A／B、EXIT等の盤面文字 | 対応する図形・紋様と色。出口は光る扉と動き |
| 「ここで分身」「1体戻す」「最初から」および補足文 | 巻き戻し・分身・取り消し・リセットのアイコン |
| 「未記録」「再生待ち」「終点で待機」「あなたの分身」 | 分身のシルエット、空枠、再生の動き |
| 「長押しで移動」、PCキー案内、ミッション・ヒント常設欄 | 主画面から撤去。必要時だけ別画面のヘルプを開く |
| 通知・勝敗の文章 | 短い視覚演出と、再挑戦／次へを表すアイコン |

- 読み上げ用のaria-labelは保つ。ラベルを画像に焼き込んで文字撤去の代用にしない。
- 色だけでは区別しない。敵の狙い・攻撃範囲・罠の危険が絵だけで読み取れるようにする。
- 通常画面を操作パネルや説明カードで埋めず、ゲームを大きく見せる。スマホでは画面と操作を同時に見られる配置を優先する。

## 反映後の確認項目
