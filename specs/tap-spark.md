# 001: TAP SPARK — 最小連携の検証企画

統括AIがゲーム・動画チームへ渡す仕様と合格基準。

- 目的: 仕様 → ゲーム → ブラウザテスト → 実プレイ動画 → 投稿草案の受け渡しを1作品で検証する。
- ゲームID: `tap-spark`。無料・広告なし・外部通信なしのオリジナル反射神経ゲーム。
- 12秒の間、盤面内の光るターゲットをタップ/クリックして得点。命中で次の位置へ移動。
- スタート、残り時間、スコア、終了結果、再挑戦を表示する。キーボードでも操作可能にする。
- 最小実装: HTML/CSS/JavaScript のみ。縦向きスマートフォンとデスクトップで動く。

## ゲーム合格条件

1. `games/tap-spark/index.html` と操作説明が存在する。
2. ブラウザで開始・命中による加点・12秒経過による終了・終了後の加点停止・再挑戦を実測確認する。
3. スマートフォン幅とデスクトップ幅で横スクロールが発生せず、主要操作が表示される。
4. JavaScript実行エラー・外部リクエストがない。
5. テスト結果を機械可読JSONで保存する。不合格なら録画を開始しない。

## 動画合格条件

1. テスト合格後のゲームをChromiumで実際に操作して録画する。画像スライドや生成映像で代用しない。
2. 動画は10〜20秒、縦9:16、MP4/H.264・yuv420pで保存し、ffprobeで検証する。
3. 開始・複数回の得点・終了結果が映る。記録した操作と得点をJSONに残す。
4. `videos/tap-spark/` に動画、台本、投稿草案、チェック結果を用意する。

## 統括確認

- 各成果物と受け渡し記録を確認し、ローカル検証完了と公開待ちを区別する。
- 公開URLは未設定として保存する。ゲーム公開・X投稿は今回実施しない。
- 人間による動画・投稿文確認、公開URLの疎通確認、Xの最新規約確認が済むまでは公開可としない。
- APIキー・認証情報・アカウント連携なしで最小検証を再実行できること。
