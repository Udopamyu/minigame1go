# #002 投石機研究所 — 修正と自動テストの履歴

対象: PIXEL TREBUCHET v0.5 / [PR #2](https://github.com/Udopamyu/minigame1go/pull/2)

## 第1回：モバイルUIとキーボード操作
- 発見: スマホの「改造」ボタンとステージ情報が重なる可能性。Spaceキーがフォーカス中のボタンを横取りし、射出してしまう。
- 修正: スマホHUDを改造ボタンの下へ配置し、目標プレビューと重ならない幅に制限。Spaceキーのショートカットはフォーム・ボタンの操作中には動作させない。
- 評価: 全10ステージ読み込み、320/390/768/1280px表示、改造UIのSpace操作。
- 検証: [GitHub Actions](https://github.com/Udopamyu/minigame1go/actions/runs/42131587843) **90/90合格**。

## 第2回：発射中のパラメーター変更
- 発見: 射出中に「解放ピン」「巻き上げ」「改造」を変更でき、物理計算が途中で変わり得る。
- 修正: 発射中は設定と改造をロック。射出完了時に自動解除。改造関数でもアイドル以外の変更を拒否。
- 評価: 発射中のコントロール無効化、終了後の有効化、射出回数の永続化。
- 検証: [GitHub Actions](https://github.com/Udopamyu/minigame1go/actions/runs/42131998899) **106/106合格**。

## 第3回：投稿動画の内容改善
- 発見: 初期装備でステージ4を録画した旧動画は破壊率0%。動画として展開が弱い。
- 修正: 初期装備のステージ1を解放ピン114°で撮影。プレイ実績を偽装せず、録画後の破壊率が0%の場合は工程を不合格とする。
- 検証: [GitHub Actions](https://github.com/Udopamyu/minigame1go/actions/runs/42132550130) **106/106合格、15.0秒縦型MP4、実プレイ破壊率40%**。
- [動画・評価証跡（GitHub Actions成果物）](https://github.com/Udopamyu/minigame1go/actions/runs/42132550130/artifacts)
