# 初回統合テスト手順（PR #1）

目的：未検証のゲーム・動画制作パイプラインを GitHub Actions の Linux / Chromium 環境で検証する。

確認する項目：
1. Chromium が起動し、TAP SPARK の開始・クリック・得点・終了・再開がテストできること
2. 実ブラウザ操作の動画が 10〜20 秒の縦型 MP4 として出力されること
3. ゲームテスト・録画チェック・統括の JSON 記録が生成されること
4. Actions の成果物に MP4 と JSON が含まれること

Actions の成功だけでゲーム公開・X投稿・収益化を意味するものではない。
ゲームと動画の人間による確認と公開URL設定は別工程。
