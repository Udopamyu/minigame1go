# #003 ロボ・サルベージ — 10,000行開発ロードマップ

## 目的
「敵を倒して4部位から1個だけ奪い、3択の分岐を進んでボスへ収束する」核を維持しながら、装備によってプレイスタイルが変わるローグライトとして商用相当の品質を目指す。

**10,000行は目標規模であり、完成判定ではない。** 無意味な行数の水増しはしない。実装・テスト・調整が必要な機能を優先する。

## 規模の計測方法
- ゲームソースは `games/robo-salvage/src/` に段階的に分割する。
- `scripts/robo_line_count.py` で実装行数／テスト行数を別々に記録する。
- ビルド生成した `index.html` は**ソースの重複**なので、ゲームソース行数へ加算しない。
- 依存ライブラリ・自動生成コード・空行は目標へ加算しない。行数とは別に機能・バグ・テストの進捗を管理。

- 自作ソース計測：**1,136非空行**（`src/game.js` 934、`src/game.css` 141、`src/template.html` 61）。生成HTMLとテストは別集計。目標まで残り **8,864非空行**。
- 武器・装甲・脚部・コアをそれぞれ4→7種類に増やし、**計28種類**の収集候補へ拡張。既存の敵装備抽選・ショップと戦利品選択へ反映。
- 敵の戦闘行動に**6ロール**追加：標準機、突撃、狙撃、回り込み、強敵守備型、最終ボス。ロールにより射程・好む距離・横移動・命中精度が変化。単純な攻撃力増加は避ける。
- 新コア「イージス」の被ダメージ軽減を能力値計算に組み込んだ。
- PC/スマホの**183/183項目自動テスト合格**。生成HTMLと編集可能な分割ソースの一致も検証済み。

続く機能優先度：武器固有の挙動（爆風・状態異常）→パーツ相乗効果→敵AIの役割強化→ボス専用攻撃。1万行は到達後の内容と品質で評価する。

## 開発ルール
1. 作業はドラフトPR #12のブランチで行い、正式公開までは`main`へマージしない。
2. ゲーム用ソース・ビルド・テストを分離し、生成HTMLは引き続き単一ファイルで試遊可能にする。
3. 機能実装ごとにPC/スマホの動作テストと、購入→戦闘→戦利品→マップの回帰テストを行う。
4. テストに通っても、ノーチートでの通しクリアや実際の面白さは本人による試遊で評価。
5. Xへの投稿やGitHub Pages公開は別の明示的な工程。

## 第2段階：戦闘ギミック実装（2026-11-13）

- 武器7系統それぞれに実際の着弾効果を追加（スタン・鈍足・装甲破砕・炎上・吹き飛ばし・爆風）。
- 反応装甲の被弾軽減、ジェット脚のダッシュ延長、補修コアの追加回復を実装。
- 敵AIに飛来する弾の回避、一部役割の低HPでの後退を追加。
- 15アリーナへ4系統の環境ギミックを組み込み、強敵・ボスでは追加ギミック。
- 最終ボスに4種類の予兆付き攻撃、第2フェーズを追加。
- テストでは実際のダメージ、状態異常、地形、敵回避、ボス攻撃・フェーズ移行を検証。
- 実装・テスト結果はドラフトPR #12に蓄積し、正式公開はしない。

**2026-11-13 第2段階の検証完了**：編集元ソース **1,396非空行 / 10,000行（14.0%）**。生成HTMLとテストを除外。残り8,604行。Chromium PC・スマホ回帰試験 **229/229項目合格**。実際のブラウザで状態異常・4環境ギミック・敵の飛来弾回避・ボス4攻撃と第2フェーズを確認。連続被弾の演出発生頻度も制限。テストは個別の効果や進行フローを確認したものであり、通常操作だけでの10マス通しクリアや難易度バランスを保証しない。

## 第3段階：設計方針確定とピクセルメカ（2026-11-13）

ユーザー決定：**戦闘は操作と戦術を同程度に重視、敗北時は装備・ゴールド全ロスト、4部位を維持して組み合わせを深化、ドット絵・メカ調。**

- 相乗効果：src/synergies.js に20の組み合わせと重ね掛け上限。火力・連射間隔・HP・移動・防御・状態異常へ適用。
- ピクセルメカ：src/pixel-art.js に装甲・武器・脚・コアによって形が変わる独自 Canvas 描画。低解像度→最近傍拡大。画像素材・外部ライブラリなし。
- 戦利品・ショップ：能力値差分と、新たに発動または失うコンボを表示。
- 敗北：現在の装備とゴールドを即時ゼロに戻す。最高到達記録のみ保存。
- ビルド：追加2モジュールを単体HTMLの即時関数に組み込む。ローカルHTML実行互換を維持。
- **編集元ソース2,026非空行 / 10,000行（20.3%）**。生成HTML、テスト、ドキュメントを除外。残り7,974行。
- **Chromium PC・スマホ自動試験281/281項目合格**。ドラフトPR #12を維持し、正式公開しない。
- 次段階：コンボを理解しやすい戦闘情報、敵のビルド特徴、装備収集の動機付け、ボスバリエーション、バランス検証。

- **16種類の戦術アーキタイプ**：有効な2部位コンボとAIの役割を対応させ、残りの装備・パーツ等級はランダム。約28%は完全ランダム構成を維持。すべてのアーキタイプが最低1つのコンボを発動することを自動検証。

## 第4段階：破壊可能な遮蔽物と射線の選択（2026-11-13）

- 15ステージの全遮蔽物に素材別耐久値を追加（瓦礫76、柱126、通常壁190、塔260、コア340 HP）。
- 武器の着弾で遮蔽物を削り、HPが0になると実際に当たり判定と射線を除去する。遮蔽物を迂回するか、破壊して突破するかを選べるようにした。
- ダメージに応じて壁の亀裂、HP残量、破壊粒子をドット絵で表示。既存の武器特性と敵AI・弾道は維持。
- 戦闘開始時に素材別HPが設定され、破壊後に移動可能になることをPC・スマホの実ブラウザテストへ追加。
- **現在 2,068 / 10,000 非空ソース行（20.7%）**。生成HTML・テスト・ドキュメント除外。
- **285/285項目のブラウザ試験合格**（GitHub Actions run 43415974723）。ドラフトPR #12を継続し、正式公開しない。
- 次の評価：強敵戦で遮蔽物が壊れる頻度、敵が破壊された経路を使えるか、ゲーム後半の火力と壁HPのバランス。
