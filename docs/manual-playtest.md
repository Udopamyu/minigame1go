# #002 投石機研究所 — 本人テストプレイ手順

対象: [PR #2](https://github.com/Udopamyu/minigame1go/pull/2) の「PIXEL TREBUCHET」最新版。

## テスト方法

ゲーム本体は `games/catapult/index.html` だけで動作する単一HTMLです。テスト版はGitHub Actionsの **Catapult downloadable playtest build** からダウンロードするZIPに入っています。

1. [テスト版の実行一覧](https://github.com/Udopamyu/minigame1go/actions/workflows/catapult-playtest.yml) を開く。
2. 最新の緑色の実行を開き、ページ下部の `catapult-playtest-html` をダウンロード。
3. ZIPを展開し、`games/catapult/index.html` をPCのChrome/Edge、またはHTMLローカルファイルを開けるスマホのブラウザで開く。
4. スマホでローカルHTMLを開けない場合は、PCで `python -m http.server 8000` をリポジトリのルートから実行し、同じWi‑Fiからアクセス（外部からのアクセス制限に留意）。公開プレビューURLはまだ発行していません。

## 本人テスト（目安15〜30分）

- [ ] スマホで「改造」とステージ表示・目標の位置関係が見える
- [ ] 解放ピン・巻き上げ操作と発射、カメラ横スクロールが理解できる
- [ ] 発射中は設定を触れず、射出完了後に解除される
- [ ] ステージ1を自然にクリアでき、次のステージへ進める
- [ ] ステージ2〜10で、少なくとも1回ずつ実プレイして目標の位置関係が把握できる
- [ ] 強化（お金、石弾・散弾・炸裂弾）の取得と切替に問題ない
- [ ] 動く気球と障害物に種類があり、単調でない
- [ ] 再読み込みしても適切に保存・復帰する
- [ ] 最終ステージまで現実的な操作・時間・強化で進められる
- [ ] 途中で遊ぶのをやめたくなる箇所がない（難易度の急変がない）

重要：GitHub Actionsの106/106合格は、画面ロードや射出操作などの自動テストです。10ステージのクリア・楽しさは本人確認が必要です。

## 公開準備の別工程

ゲーム修正と本人テストが終わるまでPRはドラフトのまま。公開URL設定・ゲームの公式告知・X動画投稿はしない。
公開前には著作権/個人情報、スマホ実機性能、音声、広告・課金がないこと、モバイル通信下の読み込みを確認する。
第1作の正式公開状況は本人からの申告を優先し、公開済みの実績にカウントしない。
