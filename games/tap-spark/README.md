# TAP SPARK

12秒で光るターゲットを何回つかまえられるかを競う、無料・広告なしの反射神経ゲーム。HTML/CSS/JavaScriptのみで動き、外部ライブラリ・外部通信・アカウント登録を使いません。

## 起動と操作

リポジトリのルートで `python -m http.server 8000 --bind 127.0.0.1` を実行し、ブラウザで `http://127.0.0.1:8000/games/tap-spark/` を開きます。単一HTMLなのでファイルを直接開くこともできます。

1. 「12秒チャレンジをはじめる」を押す。
2. 光るターゲットをタップまたはクリックすると1点。光が別の位置へ移動します。
3. キーボードではターゲットにフォーカスした状態で Enter / Space を押すと1点。開始時に自動的にターゲットへフォーカスします。
4. 12秒経過すると終了結果を表示します。「もう一度あそぶ」で得点・残り時間をリセットして再挑戦できます。

音声・課金・広告・スコア送信はありません。スコアは再読み込みするとリセットされます。キーボードはキーを押し続けるとブラウザの標準キーリピートが働く場合があるため、入力方法別のランキングはありません。

## チーム間のDOM契約

| セレクタ | 用途 |
| --- | --- |
| `body[data-state]` | `ready` → `playing` → `finished`。再挑戦で `playing` に戻る |
| `#start-button` | 初回開始ボタン |
| `#arena` | 盤面。ターゲットは盤面の内側に収まる |
| `#target` | クリック対象のbutton。プレイ中以外はdisabled |
| `#score` | 現在得点。数値のみ |
| `#time-left` | 残秒。小数1桁の数値のみ |
| `#result` | 終了時にhiddenを解除する結果領域 |
| `#final-score` | 終了得点。数値のみ |
| `#restart-button` | 再挑戦ボタン |

## テスト観点

統合検証は `python scripts/pipeline.py`、ゲーム単独テストはサーバー起動後に `python scripts/verify_game.py --base-url http://127.0.0.1:8000 --game tap-spark` で実行します。

ゲームの機械テスト結果は `games/tap-spark/test-results.json` に保存します。本ファイル自体は合格を示すものではありません。

- 初期状態はready、得点0、残り12秒、ターゲットdisabled。
- 開始後はplayingになり、ターゲット命中ごとに1点と位置変更。
- 実時間で12秒後にfinishedになり、結果の得点とHUDが一致する。
- 終了後の操作で加点されず、再挑戦すると0点・12秒から再開。
- スマートフォン幅・デスクトップ幅で横スクロールしない。
- キーボード操作、実行エラー、外部リクエストの有無を確認。
- モーション軽減の設定時はターゲットの発光アニメーションを停止。
