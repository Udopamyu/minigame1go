# #003 ロボ・サルベージ（試作）

敵ロボットと1対1で戦い、勝利後に敵が装備していた4種類のパーツから**1個だけ**強奪する、オリジナルのローグライトアリーナゲーム。

## 遊び方
- PC：WASD / 矢印で移動、マウス長押しで照準射撃、Spaceで敵に自動照準射撃、Shiftでダッシュ。
- スマホ：左の仮想スティックで移動、FIRE（自動照準）、DASH（回避）。
- 敵は武器/装甲/脚部/コアがランダム。4部位それぞれ武器特性や装甲値などが異なる。
- 倒したら敵の4つの装備が戦利品として現れ、その中から**必ず1つだけ**選ぶ。自機の対応部位と入れ替える。
- ラウンドを進むほど敵のパーツレベル・レアリティが高まり、敵が強くなる。
- 敗北でランが終了。ベストラウンドだけローカルストレージに保存。

## 実装範囲
オリジナル機体/パーツ名/Canvas描画のみ。既存ゲームの名称・デザイン・素材を複製しない。

## 実行
`games/robo-salvage/index.html` をブラウザで開くだけ。外部ライブラリ・通信不要。

## 全画面モード（試作v0.2）

- アリーナをブラウザの表示領域全体（`100dvh × 100vw`）へ拡張し、周囲のパネル・ヘッダー・文章を常時表示しない。
- 左上の **☰** メニューから装備・敵機体・HPを確認。表示中は戦闘を一時停止し、閉じると再開。サウンド設定もメニュー内。
- 戦闘画面の文字HUDと機体名は非表示。スマホではジョイスティックとFIRE/DASHのみ常時表示。
- スマホ縦画面ではアリーナの描画を90°回転し、敵が画面上、プレイヤーが下になる。スティックの上下左右も画面の向きに一致。
- 縦横とも戦場はアスペクト比を保持しながら画面全体を覆う。画面比率によってアリーナの外縁は一部切り取るが、ロボットの形は変形しない。
- 敵のダメージを14%軽減、移動速度を約8%減、射撃間隔を約12%延長。倒した敵から入手するパーツ性能は変更しない。
- GitHub Actions: **63/63** のPC・スマホ操作/全画面/メニュー一時停止/戦利品1個交換のブラウザテストに合格。
- ゲーム本体はまだ公開せず、PR #12から手動試遊を行う。
