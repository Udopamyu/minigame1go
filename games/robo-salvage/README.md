# #003 ロボ・サルベージ（試作）

敵ロボットと1対1で戦い、勝利後に敵が装備していた4種類のパーツから**1個だけ**強奪する、オリジナルのローグライトアリーナゲーム。

## 遊び方
- PC：WASD / 矢印で移動、マウス長押しで照準射撃、Spaceで敵に自動照準射撃、Shiftでダッシュ。
- スマホ：左の仮想スティックで移動、FIRE（自動照準）、DASH（回避）。
- 敵は武器/装甲/脚部/コアがランダム。4部位それぞれ武器特性や装甲値などが異なる。
- 倒したら敵の4つの装備が戦利品として現れ、その中から**必ず1つだけ**選ぶ。自機の対応部位と入れ替える。
- ラウンドを進むほど敵のパーツレベル・レアリティが高まり、敵が強くなる。
- 敗北でランが終了。ベストラウンドだけローカルストレージに保存。

## 実装範囲
オリジナル機体/パーツ名/Canvas描画のみ。既存ゲームの名称・デザイン・素材を複製しない。

## 実行
`games/robo-salvage/index.html` をブラウザで開くだけ。外部ライブラリ・通信不要。

## 全画面モード（試作v0.2）

- アリーナをブラウザの表示領域全体（`100dvh × 100vw`）へ拡張し、周囲のパネル・ヘッダー・文章を常時表示しない。
- 左上の **☰** メニューから装備・敵機体・HPを確認。表示中は戦闘を一時停止し、閉じると再開。サウンド設定もメニュー内。
- 戦闘画面の文字HUDと機体名は非表示。スマホではジョイスティックとFIRE/DASHのみ常時表示。
- スマホ縦画面ではアリーナの描画を90°回転し、敵が画面上、プレイヤーが下になる。スティックの上下左右も画面の向きに一致。
- 縦横とも戦場はアスペクト比を保持しながら画面全体を覆う。画面比率によってアリーナの外縁は一部切り取るが、ロボットの形は変形しない。
- 敵のダメージを14%軽減、移動速度を約8%減、射撃間隔を約12%延長。倒した敵から入手するパーツ性能は変更しない。
- GitHub Actions: **63/63** のPC・スマホ操作/全画面/メニュー一時停止/戦利品1個交換のブラウザテストに合格。
- ゲーム本体はまだ公開せず、PR #12から手動試遊を行う。

## 戦場とルートマップの刷新 v0.4（開発ブランチ）

- **ステージ外形を変更**：従来の四角い戦場に加え、楕円形、八角形、中央がくびれた戦場、角を大きく落とした戦場の5系統を実装。外形の外側には移動できない物理判定がある。
- **15種類の本格的な構造**：中央要塞、長い狭路、柱の森、左右に分かれた部屋、らせん状の障害物、コロシアムなど、同じ四角いブロックが3個だけ並ぶ構造を解消。障害物は武器弾道とロボットの移動を遮る。
- **敵の経路追従**：複雑な障害物で敵が壁に張り付いて動けなくならないよう、障害物で停止した場合は壁沿いに進む回避移動を追加。
- **分岐マップを全体表示**：10階層 × 5列のマスを地図に並べ、マス同士を線で接続。現在の位置から隣接3方向を選択し、選んだ経路は光る線で残る。最終階層の後は全ルートが中央の**ボスマス1個**に収束する。
- **マップの内容**：各周回で特殊マスと敵の配置がランダムに変化する。戦闘マスが多数を占め、強敵、ショップ、イベント、休憩、資材庫が混在する。
- **画面構成**：戦闘中は引き続き全画面・低情報量。ルート選択時だけスクロール可能な縦長の専用マップ画面を表示する。
- **公開状態**：PR #12は引き続きドラフト。本人の試遊前にGitHub Pagesへ公開しない。

## ローグライト探索 v0.3（開発ブランチ）

**10マスの3択分岐を進み、11戦目相当の最終ボスへ合流**する探索型ループを追加。

- **戦闘マスが中心**：毎回「通常戦2候補＋特殊マス1候補」の3択。敵装備は毎回ランダム。
- 特殊マス：**強敵**（高HP／高報酬）、**ショップ**、**イベント**（補給・修理・改造の選択）、**休憩**（45%回復）、**資材庫**（ゴールド獲得）。
- **ボス**：10マスクリア後に3択が収束。高耐久の最終ボスを倒すと周回クリア。
- **HP**：プレイヤーと敵の基礎最大HPを従来の2倍に変更。戦闘勝利直後、最大HPの **30%** を回復（最大HPまで）。
- **ゴールド**：通常戦で55＋進行深度×13 G、強敵で112＋深度×22 Gなど。所持額は左上の装備メニューと進路画面で確認。
- **戦利品**：勝利時は従来の4候補から1パーツを奪うか、**スキップして40＋深度×9 G** を追加獲得するか選択。
- **ショップ**：ゴールドを使い、HPを35%修理、4部位をLv.+1、ランダムな販売パーツ2個から購入・付け替えが可能。所持金不足なら購入不可。
- **ステージ地形**：遮蔽物の配置を従来の3パターンから**15パターン**へ拡張。周回中は10マスごとに異なる配置を使用し、敵やショップの構成も変動。
- **画面**：戦闘時は全画面と操作ボタンのみ。進路選択・ショップ・戦利品・イベントは専用のオーバーレイで表示。左上メニューで戦闘を一時停止できる。

内部実装：`depth` は完了したマスの数。開始時は0、10マス完了後は`boss`の1択のみ。戦闘開始時に勝手な回復はしない。ショップでは敵装備を奪えず、ゴールドで交換/改造する。

QA：ブラウザ上で10マスの実際のルート進行、ゴールド・30%回復、戦利品スキップ、ショップ購入、イベント/休憩、ボスへの収束を検証。難易度の体感と完全ノーチートクリアは人間の試遊で確認する。
