# ロボ・サルベージ | ミニゲーム1GO #003

武器・装甲・脚部・コアを奪って機体を組み替える、無料・広告なしの1対1ローグライト戦闘ゲーム。

**公開状態：v0.14 公開候補（GitHub Pages未公開）。** 技術テストは合格。序盤の難易度、ボスまでの攻略可能性について人間の最終試遊が必要です。

## 遊び方

10マスの分岐ルートを進み、最後のボスを倒す。敵を倒すと相手の装備4部位から1つを奪うか、解体してGOLDを得られる。GOLDはショップで使用。装備の組み合わせで20種類のコンボが発動する。

敗北で周回中のGOLDと装備は失うが、周回で得た研究ポイント（SP）と購入済みの永続強化は残る。初期武器はパルスガンが無料、ほか7種類はそれぞれ40 SPで解放。コアはバランス・パワー・スピード・タクティカルの4種類。

## 操作

| 操作 | PC | スマートフォン |
| --- | --- | --- |
| 移動 | WASD / 矢印キー | 左の仮想スティック |
| 射撃 | Space、マウス長押し | FIRE |
| ダッシュ | Shift | DASH |
| 手動リロード | R / RELOAD | RELOAD |
| 装備・ステータス | 左上 ☰ | 左上 ☰ |

弾倉容量とリロード時間は武器別。空弾倉になると自動リロード。☰ メニューは現在の機体性能レーダー、装備コンボ、相手の装備を表示し、戦闘中は一時停止する。

## セーブデータ

SP・永続強化・解放済み初期武器・最高到達地点は、利用しているブラウザのローカルストレージに保存。サーバーや別端末には同期されず、ブラウザデータを削除すると失われる。外部アカウント登録・課金・広告・ネットワーク接続は必要なし。

## 実行と検証

`games/robo-salvage/index.html` を直接開けばプレイ可能。ソースは `src/` に分割し、`python scripts/build_robo_salvage.py --check` で配布HTMLとの一致を検証する。

- PC/スマホのブラウザQA、Playwright操縦による試遊：`scripts/verify_robo_salvage.py`、`scripts/robo_playtest.py`
- 公開準備の静的検証：`python scripts/robo_release_preflight.py`
- 最新の結果は [GitHub Actions](https://github.com/Udopamyu/minigame1go/actions) で確認。過去の緑色表示を新しいコミットの合格と取り違えないこと。

**公開前の確認事項・公開手順：** [公開チェックリスト](../../docs/robo-salvage-release-checklist.md)。技術テスト合格だけではクリア可能性や難易度の妥当性は保証されない。
