## 最新の仕様で最優先すること
- 低空ホバー＋前後左右移動。左スティック無入力で停止。旧版の「常に飛び続ける」挙動は採用しない。
- 自機は画面下、敵は中央付近。両機を見失わない追従カメラ。
- 敵追従・レティクル照準一致・射線確保・射撃実行は別状態。
- 立体地形・建造物と、実際の衝突／射線遮断を一致させる。遮蔽物で敵弾を回避できること。
- 敵AIは背後への張り付きではなく、距離維持・横移動・後退・遮蔽利用・詰まり回避。
- 細密なピクセル調、飛行メカ造形、武器別の見やすい弾道、黒基調のすごろく型分岐マップ、約2秒の3D破壊演出。
- 通常戦闘画面の文字を極小化する。
