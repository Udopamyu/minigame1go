## 操作

| 入力 | PC | スマホ |
| --- | --- | --- |
| 移動（視点基準・前後左右） | WASD | 左スティック |
| 視点（離すと敵追従へ戻る） | 矢印キー／マウスドラッグ | 右スティック |
| 上昇／下降 | Space／C | ▲／▼ |
| ダッシュ | Shift | » |
| 手動射撃 | J・F・K／左クリック | ◎ |
| リロード | R | ↻ |
| 調整パネル | T／⚙ | ⚙ |

- **自動射撃ON（初期値）**：敵が中央の照準円に入り、射線が通り、射程内の時だけ撃つ。追従しているだけでは撃たない。
- **手動射撃**：ON/OFFに関係なく、照準の方向へいつでも撃てる。ロック中は敵を狙う。
- 手を離すと短く減速して空中に静止する。上を向いて前進すると上昇、下を向くと下降。高く飛び続けるとEN（黄色ゲージ）を使い、尽きると降りる。

## v0.6 で作り直した部分

v0.5は2D版→TPS→ハイブリッド→自由飛行→ラボ→v0.5の上書きが6層重なり、**シェーダーの地面と当たり判定用の地面が別の形**でした（画面の地形と衝突が一致しない）。この環境のChromeでは1.7fpsでした。v0.6は戦闘部分を1つのモジュールに作り直し、格納庫・ルート・戦利品・ショップ・SPなどの進行部分はv0.5のまま使っています。

| ファイル | 内容 |
| --- | --- |
| `src/core.html` | ロボサルベージの進行部分（v0.5から変更なし。WebGL2非対応時の2D戦闘もここ） |
| `src/b3-world.js` | 設定、地形（高さマップ）と障害物、当たり判定、射線。**描画と判定が同じデータを読む** |
| `src/b3-render.js` | WebGL2描画、装備で形が変わる機体モデル、カメラ行列 |
| `src/b3-game.js` | 入力→移動→敵AI→カメラ→ロック・射撃→弾→撃破演出 |
| `src/b3-ui.js` | 毎フレームの描画、文字なしHUD、タッチ操作、調整パネル、既存コードとの接続、テスト用フック |
| `src/tail.html` | 起動処理 |

編集後は `python scripts/build_patrol_salvage.py` で `index.html` を再生成します（`--check` で一致確認）。

## 遮蔽の例外ルール

| 武器 | 遮蔽物（建物・岩） | 地形（地面・山） |
| --- | --- | --- |
| 通常弾（パルス・散弾・ニードル・バースト・スラグ） | 止まる | 止まる |
| レールランサー | **貫通する**（2D版の「壁を貫く」を継承） | 止まる |
| ホーミング弾 | 当たると爆発。爆風は遮蔽物越しには届かない。誘導で回り込む | 止まる |
| リコシェット | 面の向きで反射（最大3回） | 反射 |
| ボスのビーム | 止まる（3Dの射線で判定） | 止まる |

## 保存

- 進行・SP・初期武器の解放は2D版と同じ `roboSalvageMetaV1` を使う（同じドメインでは共有）。キー名・形式は変えていない。
- 操作調整は `patrolSalvageHoverTuneV06` に保存する。旧ラボの `patrolSalvageFlightTuneV04` は読み書きしない（消してもいない）。
