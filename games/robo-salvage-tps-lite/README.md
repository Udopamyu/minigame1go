# ROBO SALVAGE — Pixel TPS Lite（操作・描画検証版 v0.1）

作成日：2026-11-17。2D版の既存ゲームと、以前のThree.js TPS試作とは**別の、軽量Canvas実装**です。

## 目的と技術

- PIXEL SHIFT v0.3の設計を応用：低解像度Canvas、同一の3Dワールド座標・透視投影、積層ドット絵由来の露出ボクセル面の生成・面結合・陰影・カリング。
- カメラは常にTPS。俯瞰への切替は廃止。
- スマホは左スティックで前進／後退／左右移動、右スティックでカメラ・照準を上下左右に回す。
- 前進の自動入力はない。左スティック・WASDを離した時、通常時は移動停止。
- レティクル内に敵が入り、遮蔽物で隠れていなければ自動射撃。敵から照準が外れると射撃停止。銃弾は弾倉・装填時間を持つ。
- パルス：狭い範囲／12発、ショットガン：広い範囲／5発、ミサイル：最も広い範囲／4発。レティクルは武器に応じ形と大きさを変える。ミサイルには捕捉までの遅延と追尾効果。
- 左スティックを同方向へ素早く2回倒すと瞬間横回避。左上側にも任意回避ボタンあり。回避は短時間の被弾無効とクールダウンを持つ。
- 敵に射撃予告線、弾道・物理衝突・遮蔽物、簡易AIの間合い・横移動を実装。
- 4部位（武器／装甲／脚部／コア）を維持し、3連戦後にボス。各戦闘後にパーツを1つ交換する暫定サルベージメニュー。武器・パーツに応じて形状と挙動を変更。
- ゲーム通常画面の文字はなし。説明・装備選択は別メニューのみに表示。

## 操作

| 機能 | スマホ | PC |
|---|---|---|
| 前後・左右 | 左スティック | WASD |
| カメラ・照準 | 右スティック | 矢印またはマウスドラッグ |
| 射撃 | レティクル内に敵がいると自動 | 同じ |
| 横回避 | 左スティック同じ横へ二度倒す／左上の二重矢印 | Shift＋A/D |
| リロード | 自動、右上の丸矢印でも可 | 自動、R |
| ポーズ・試射武器切替 | 左上ポーズアイコン | P |

試作版はポーズ画面から**パルス／ショットガン／ミサイルを試験用に即時切替可能**。ゲーム内パーツ取得の正式な解放方式は未接続。

## テスト（2026-11-17、Chromium）

- PC1280×720：14/14の操作・射撃・停止・視点移動・回避・試射切替テスト合格。
- スマホ縦390×844：11/11合格。2点同時の実タッチイベントで左右スティックが独立動作。離すと中立。
- スマホ横844×390：11/11合格。同条件。
- 合計36/36チェック、JS例外なし。自動試験環境では約60fps。
- 人間による3セクター通しクリア、長時間負荷、実機fps・発熱は未検証。
