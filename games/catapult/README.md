# 投石機研究所 — PIXEL TREBUCHET (v0.5)

別チャットで開発中だったゲームを、原本のまま次作品の評価用ブランチに取り込みました。

- 起動: `games/catapult/index.html` をブラウザで開く（またはローカルHTTPサーバー）。
- 操作: 解放ピンの角度、巻き上げ量を調整して「投 石 !!」。横スクロールで目標を確認。GOLDで改造し、別弾種も解禁。
- ステージ: 10。ステージ3以降で気球、ステージによって障害物が変わる。
- 改造ボタンはモバイルで左上。
- 公開ステータス: 未評価・未公開（このブランチから実際にゲームを公開しない）。

評価後に修正が必要な場合はゲーム制作部門へ差し戻します。
