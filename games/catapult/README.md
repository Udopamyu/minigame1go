# 投石機

別チャットで制作した投石機ゲーム。修正と自動テストを経て公開候補となった版です。

- 起動: `games/catapult/index.html` をブラウザで開く（またはローカルHTTPサーバー）。
- 操作: 解放ピンの角度、巻き上げ量を調整して「投 石 !!」。横スクロールで目標を確認。GOLDで改造し、別弾種も解禁。
- ステージ: 10。ステージ3以降で気球、ステージによって障害物が変わる。
- 改造ボタンはモバイルで左上。
- 公開ステータス: PR #2のマージ後、GitHub PagesでWeb公開。Xの正式告知は別工程。

自動テストは合格済み。正式な公開告知の前に実機で最終確認してください。
