# #003 ORBIT SWITCH / 軌道スイッチ

**状態: 実装・評価中（ドラフトPR）。公開およびX投稿はまだ承認されていません。**

単一HTMLで動く無料・広告なしの30秒ワンボタンゲームです。外部CDN、画像、音源、有料APIは使用しません。

## 操作
- 開始：MISSION START
- プレイ中：画面タップ、下部「軌道を切り替える」ボタン、またはSpaceで内側/外側を変更
- 赤い障害物を避け、反対側の光る星を回収（1個10点）
- 3回被弾すると終了、30秒生き延びればクリア
- RETRYで再挑戦。ベストスコアはブラウザ内に保存
- 音は初期設定OFF。右上でON/OFF可能

## ローカル起動
リポジトリのルートで python -m http.server 8000 を実行し、http://localhost:8000/games/orbit-switch/ を開いてください。index.html を直接開いても動作します。

## 検証
- python scripts/verify_orbit.py — 4種類の画面サイズ、実ブラウザでの開始/操作/終了/再挑戦、3被弾、30秒サバイバルのロジック、ベスト記録、JSエラー、外部リクエストをテスト。
- ?e2e=1&seed=321 はローカル/CI専用の決定的テスト補助（シミュレーション進行）を有効化します。**録画・通常プレイには使わないこと。**
- テスト成功でもスマホ実機操作、ゲーム性、実プレイ動画、公開URLは人間の別途承認が必要。
- 結果とキャプチャは evaluation/orbit-switch/ に出力。CIアーティファクトで確認。

## 設計
1画面ワンボタン、30秒。10秒ごとに回転速度が上昇します。ゲートは必ず一方の軌道だけが危険で、もう一方は安全。初手は内側に危険があり、切替操作を促します。固定シードを使えば同じ障害物系列を検証できます。
