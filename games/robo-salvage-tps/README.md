# ROBO SALVAGE 3D TPS — 派生試作

既存の 2D ローグライト games/robo-salvage/ を変更せず、4部位サルベージのルールを3D TPSに再構築した試作です。

## 実行
games/robo-salvage-tps/index.html をWebGL対応ブラウザで開きます。Three.js ES ModuleをCDNから取得するためネット接続が必要です。静的ホスティングで動作する設計です。

## 操作
- PC: WASD / 矢印で移動、マウスで視点、左クリックで射撃、Shift / Spaceでダッシュ、Pでメニュー、Escでマウス解除。
- スマホ: 左仮想スティックで移動、画面右側をスワイプして視点変更、FIREで射撃、DASHで回避。射撃時に照準近傍の敵を弱くアシスト。

## 試作の内容
- 3D肩越しTPS、立体遮蔽物の移動・弾道衝突、複数敵の距離管理と横移動。
- 武器5種・装甲4種・脚部4種・コア4種。4部位の能力と外見が変化。
- 敵撃破後、4部位から1つを奪取して自機の該当部位と交換。または解体して資材を得る。
- 6セクター。各戦後に通常戦・強敵・整備から選択。最終戦は護衛付きのボス。
- 敗北時に装備を全ロストして再出撃。ベスト到達セクターのみ保存。
- モデル・戦場形状は手続き生成であり画像アセットは使っていません。
