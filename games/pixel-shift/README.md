# PIXEL SHIFT — 俯瞰↔TPSの「1台のカメラ」とSprite Stacking

2026-11-17制作の独立した試作ブラウザゲームです。`index.html` を開くだけでプレイできます。外部ライブラリ、WebGL、画像アセット、ネットワーク通信は不要です。

## 狙い

1作目の**15層Sprite Stacking**と、3作目の**軽量な地形・透視投影**を統合。

以前のv0.2の「俯瞰キャンバスとTPSキャンバスを重ねてクロスフェード」方式ではなく、
**地形、車、ゲート、障害物が同じワールド座標に存在し、3Dカメラの位置と方向を変化させる方式**。

俯瞰ではカメラを高い位置（約510ワールド単位）から約77度下向きに、TPSでは車の後方・低い位置（約49単位）から約6度下向きに配置。両者の位置・注視点・焦点距離を滑らかに補間し、同一の投影行列で再描画する。視点遷移中も物体が同じ世界の位置を保つ。

## 軽量化

- 描画は低解像度Canvas 2D（PC例 540×304、スマホ縦 269×582）＋最近傍拡大。
- Sprite Stackingは車15枚、小道具16～22枚のオフスクリーンCanvasを起動時に生成・再利用。
- 道路と丘は少数の高さつき帯ポリゴンで表現。奥の地形は帯の横分割数を削減（LOD）。
- 近傍の木だけ積層描画、遠方は簡易シルエットにする。
- 構造物・リングは進行方向で可視距離を判定し、画面外の描画を削減。
- すべて単体HTMLで約20KB。汎用3Dエンジンなし（透視投影は独自の簡易計算）。

## 操作

- A/D、左右矢印：左右への移動（コースは自動前進）。
- Space / Shift / 上矢印：ブースト。
- C / V / Tab、右上カメラアイコン：俯瞰とTPSを往復切替。
- スマホは左下の左右、右下の稲妻、右上のカメラアイコン。通常プレイ画面は文字なし。
- 出現する光のリングを通り、赤い障害物を避ける。練習のためHP制限はない。

## v0.2：TPS視点の「平面的な物体」を3D化（2026-11-17）

前バージョンは、積層した2Dスプライトを画面に向けて回転し、TPS時に縦方向へ圧縮していた。このため低い視点で車・樹木・障害物が平板に見えた。

- **本体の原因を修正**：`makeLayer()`で生成した15〜22枚のスプライトを、起動時に粗いボクセル（車2.5px格子、背景3.5px格子）へ変換。隣接ボクセルに隠れた面を除去し、同色の隣接面を結合（greedy meshing）。カメラ方向に応じた面カリングと深度順描画を行う。
- **側面のある実体**：車164面、樹木180面、塔63面、障害物80面の露出面を立体ポリゴンとして投影。上面・左右面・前後面に異なる陰影を設定。車体のドット絵もキャビン・ホイール・ライトを再調整。
- **道路・背景**：高さマップで左右の丘を高くし、明暗を増やす。遠景は従来の平面的な棒を3D簡略プリズムに置換して描画負荷を抑える。
- **ゲート**：1本の円形ラインから、厚みを持ったリング状の3Dプリズム（前・後・内・外の面）に変更。
- **カメラ**：同じワールド座標・同じ投影を使う単一カメラの俯瞰↔TPS切替を維持。クロスフェードへ戻していない。
- **性能検証**：Chromium PC 1280×720、スマホ縦390×844、横844×390で視点切替→ブースト→再切替に成功。いずれもJS例外なし・自動試験で60fps。描画呼び出しは最大約2,330/フレームで、旧版より増加している。実機の長時間試遊・省電力・発熱・低スペック機のfpsは未検証。

**状態**：ドラフトPRの開発版HTMLのみ更新。正式公開／mainマージ／X投稿は実施しない。


## v0.3：キレのあるドリフト旋回と側面の見せ方（2026-11-17）

- 従来は `car.heading = roadTangent + steering*0.11` だったため、車の姿勢変化が最大6.3度でTPS時に正面／背面しか見えなかった。
- 横移動速度を入力に追従する状態量 `car.sideV` とし、実際の移動方向から車体の目標ヨー角を算出。視認性のため最大約1.12 rad（約64度）までのアーケード的な誇張を許容。
- 入力中は約17〜23/sで向きを切り替え、解放時は9/sで正面へ復帰。反転操作時は特に速く切り返す。カメラは道路接線方向を基本とし、車体の側面が隠れない。
- `stack()` で車メッシュの頂点・法線を同一のロール変換で回し、左右旋回に応じた車体の傾き（最大約10度）を追加。車・木・障害物の立体メッシュは維持。
- 路面には左右のタイヤから発生した短い残像を同一ワールド座標で描画。2.1秒でフェードアウト。衝突・リング通過判定、単一3Dカメラの俯瞰↔TPS遷移は保持。
- **ブラウザQA**：Chromium PC 1280×720、スマホ縦390×844、横844×390。通常入力で左旋回約−59度、右への切返し約+57度、解放後0.4秒で約+1〜2度を確認。往復カメラ切替、ブースト加速、JS例外なし。ヘッドレス計測は約60fps（実機速度保証なし）。
- 正式公開・mainマージ・X投稿なし。レビュー用ドラフトPRに保存。
