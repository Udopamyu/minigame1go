# 10秒分身ダンジョン — v0.2 試遊用移植版

既存のChatGPT Siteとは別のオフラインHTML試遊版です。**元Siteの内容やURLは更新していません。**
`index.html` をPC・スマホのブラウザで開いて操作します（ライブラリ・サーバー不要）。

## 操作
- PC: 矢印/WASD 移動、J/Space 剣、R/Enter 巻き戻し、Z/Backspace 分身取り消し。
- タッチ: 4方向パッド、剣、青い巻き戻し、紫の取り消し。
- ルール: 10秒以内の位置・方向・攻撃を記録して最大3体の分身で再生。巻き戻すと敵と罠は初期化。倒れた分身はループ終了まで停止。
- ステージ: スイッチ（1–3）→盾敵の挟撃（4–5）→突進を罠へ誘導（6–7）。

ゲーム中の文字表示はなし。説明は「？」を開いたときだけ表示。保存はこの移植版専用キー `echoDungeonGithubV1`（既存Siteの保存データは移行していません）。
