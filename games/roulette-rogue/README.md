## コンセプト

ユーザーはカジノの胴元。来店した客は赤・黒・奇数・偶数・高・低へ賭ける。ルーレットで客が勝つと胴元の銀行から払い、外すと掛け金が銀行に入る。客の財布が0になればK.O.でボーナス獲得。胴元銀行が0以下になるとゲームオーバー。実際のお金は一切動かない架空のゲーム。

## プレイ方法

1. [index.html](index.html) をブラウザで開く、またはリポジトリのルートで `python -m http.server 8000` を実行し `http://localhost:8000/games/roulette-rogue/` を開く。
2. 最初にランダム3択から強化を1つ選ぶ。数字マスの強化は任意の番号0〜12に配置でき、重ね掛けも可能。
3. 客が賭けた色・数字条件と金額を確認し、「SPIN THE WHEEL」を押す。
4. ボールが止まったら、客ごとに1回だけ `-1` / `+1` 番号へずらせる（強化で拡張可能）。止まった番号で確定して決済。
5. 客の財布を尽くすか制限スピンを使い切ると客が帰る。客ごとに新たなランダム強化3択。6人の来店後にリザルト。

## 現在の試作品

- **13区画 (0〜12)** の簡略ルーレット。現実の欧州式37区画ではない。
- お客6人。試作は数分で遊ぶ構成。30分ランは将来の拡張目標。
- **30種類の実装済みアップグレード**：15種類の番号マス設置型＋15種類の全盤面型。数値別徴収、被害軽減、0確率アップ、追加ずらし、入場料、毒、重ね掛けコンボ等。
- ランダム抽選で表示される3候補から1つ選択。客の賭け方、資金、ターン数が進行に伴い変わる。
- HTML + CSS + JavaScriptのみ。外部CDN・有料API・広告・課金・リアルマネー要素なし。
