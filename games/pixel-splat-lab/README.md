# Pixel-art Splat — 試遊用ゲーム2作品（2026-11-18）

**開発ブランチ専用。正式公開・mainマージ・X投稿なし。** 以前開発を中止したロボサルベージTPS版のコードは使用していない独立作品。

## ① [SPLAT BREAKER](01-splat-breaker.html)
- 敵、プレイヤー、アリーナを3D座標の点群としてCanvas 2Dに透視投影する高速アクション。
- WASD / 矢印で移動、Space / Shiftで突進。スマホは左スティック＋稲妻の突進ボタン。
- 突進で敵を粉砕すると多数の粒子が飛散。回収すると機体が大きくなり、最大HPが部分回復。ただし当たり判定と移動速度にトレードオフが生まれる。次ウェーブも存在。

## ② [PARALLAX BRIDGE](02-parallax-bridge.html)
- 飛び石状の浮遊島。散乱した3D粒子を正しい視点から見ると橋に整列する錯視パズル。
- 3Dの粒子位置は特定方向の奥行きオフセットと高さ補償から生成。ビューアーの回転で投影座標を変え、**角度が合ったときのみ通行可能**にする。角度を外して歩くと落下し、直前の島へ戻る。
- カメラ回転 A/D または左右矢印、前後移動 W/S または上下矢印。スマホでは4ボタン＋ドラッグ回転。4区間でクリア。

## 技術・性能上の留保
- 双方とも外部ライブラリ・WebGL不要、`<canvas>` を低解像度で描画しCSSで最近傍拡大。**正式な3D Gaussian Splattingではなく**、多数の3D点を自前の投影で画素として描く Pixel-art Splat風の独自実装。
- PC1280×720・スマホ縦390×844・横844×390のChromiumで描画・初期起動・JavaScript例外なし。
- ① PC/スマホで突進・敵破壊・粒子吸収を確認。スマホは2点タッチの同時移動＋突進も確認。
- ② キーによる回転・4橋の通過・ゴールまで確認。スマホは長押し回転の実タッチ入力を確認。
- 実機FPS・熱・バランスの人間試遊は未評価。これらは試作に過ぎない。
- プレイ画面の文字は極力撤去し、必要な操作説明は開始時のみ表示。
