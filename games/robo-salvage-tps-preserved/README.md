# ロボ・サルベージ TPS — オリジナルUI・進行を保持する試作

> **位置付け：ユーザーからの「変わりすぎ」を受け、2026-11-17に作り直した検証用TPS。**
> 元の2D公開版は一切書き換えず、別のHTMLファイルに原本ソースを複製し、戦闘描画と入力のみを上書きしています。正式公開・mainマージ・X投稿は行わない。

## 変更しないもの（mainのオリジナルをそのまま保持）

- タイトル→**格納庫（8初期武器・SP永続強化）**→**10マス分岐SVGマップ**→戦闘→勝敗→部品4択／解体→次ルート→ボス→エンドレス
- ショップ・イベント・休憩・資材庫・敵役割・4部位の装備・20装備コンボ・コア別性能値・研究SPとセーブ
- 元のHTML構造・CSS・配色・文字・装備カード・ルートマップ・メニュー。新デザインへの差し替えは一切しない。
- 戦闘の論理座標、速度計算：装備ごとの**実移動速度（初期ローラー223）**、ダッシュ710のインパルス、既存の遮蔽物当たり判定・攻撃力・弾倉容量・敵の戦術。

## 変えるもの（戦闘中のみ）

- オリジナルの俯瞰描画から、**一人称ではなく肩越しTPS**に切替。戦闘以外は完全に元の2D描画。
- 同一のフィールド論理座標を透視投影し、ブロックを高さのある立体物、地表を低コストの高低差地形として描く。
- 既存のドット絵（`drawLegEquipment` / `drawArmorEquipment` / `drawCoreEquipment` / `drawWeaponEquipment`）をCanvas上に一度描き、画素色と形から**低ポリゴンのSprite Stacking風積層立体**を構築。機体シルエットは元作品の装備ごとに変化。
- **左スティック・WASD**はカメラ相対の前後左右移動、**右スティック・矢印キー**はカメラ旋回。射撃は敵がレティクル内・射線ありのときのみ自動（銃種ごと捕捉幅を変更）。
- 任意ジャンプ・短時間ホバー（Space・↑ボタン）。重装甲・重脚ほど浮遊時間を短く設定。**この試作では高度と弾道の3D当たり判定はまだ統合しておらず、飛行による攻撃回避は保証しない。**
- スマホの戦闘中のみ右カメラパッドとホバー用アイコンを追加。FIREを非表示にして、DASHとRELOADは元ボタンを残す。

## 実行

- `games/robo-salvage-tps-preserved/index.html` は**160KB超の完全自己完結HTML**。GitHubからダウンロードしてオフラインで起動できます。
- ChatGPTの試遊用ローダー `Robo_Salvage_TPS_Original_UI_v03.html` は既存の公開版HTMLをGitHub rawから取得し、同じ差分を挿入します。このローダーはネット接続が必要です。
- browser file:// で起動すると、公開GitHub Pagesとはローカルストレージのオリジンが異なるため、公開版のSPやBESTは自動継承されません。既存の保存データを上書き・削除はしません。

## v0.4：2D版メカの外観を維持した高密度TPS／7フィールド／高速化（2026-11-17）

前の独自TPS機体は見た目が公開2D版と離れすぎたため、**オリジナルの4種類の装備描画関数を直接呼び、装備固有のシルエットと色を縦方向に積層して立体面を構築**する方式へ調整。

- 機体：元の武器8種、装甲7種、脚部7種、コア4種をもとに、6px単位で色を抽出。中央シャーシ、砲身、左右ユニットの高さを変え、**上面・側面を別の陰影**で描く。モデルは機体/敵の装備構成ごとにキャッシュする。人型へのデフォルメはしない。
- 移動：**戦闘中だけ**オリジナルの装備別基本速度に1.25倍を掛け、元の衝突処理を維持したままダッシュの移動量をさらに約1.3倍。移動中の2本の発光軌跡、ダッシュの速度線、画角ワイド化、ホバー推進炎を追加。スティックがニュートラルのときは停止（慣性走行なし）。射撃は従来のレティクル自動発射。
- **戦闘フィールド7種類**（各戦闘の進行深度で循環）：①荒野／メサと赤茶色の崖、②砂原／明るい砂丘、③雪山／積雪の樹木・寒色稜線、④山岳／岩稜と緑の山肌、⑤市街地／ビル群と舗装、⑥川／水面と岸辺、⑦スタジアム／外壁と観客席。地平線・空・遠景・地形色・装飾物を変更。川の水は今の試作では視覚演出であり、流速や水中物理は未実装。
- 描画：低解像度Canvas/透視投影、段階的な遠景の簡略化、遠方装飾カリング、既存スプライトメッシュの事前キャッシュを維持。
- **不変**：オリジナル格納庫/研究SP/初期武器/分岐マップ/ショップ/戦利品選択/永続強化/20種類の装備コンボ/セーブキー。本線2D版のページは触らない。
- **留保**：フィールドの高低差や水面はTPS表示上のもの。衝突・弾道・射線の完全3D化は未実装。表示上の岩・樹木・建造物は基本的に背景装飾であり、元の2D物理判定と一致するとは限らない。
