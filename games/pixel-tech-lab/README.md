# Pixel Tech Lab — 3つの独立した擬似3D技術デモ

2026-11-17制作。**正式公開前の試遊用ブランチ**。ユーザーが共有した3つのX投稿を起点にした新規制作です。

- [01-sprite-stack-drift.html](01-sprite-stack-drift.html)：車体15層のSprite Stacking。左右旋回・加速で光を収集。PCは左右／ADキー、上／Spaceで加速。スマホは下部のアイコン。
- [02-splat-garden.html](02-splat-garden.html)：独自の3D粒子座標を透視投影し、浮遊する庭を描く。6つの花に触れると点灯。PCは矢印／WASD移動、Q/Eカメラ回転。スマホはドラッグ移動、右下の回転アイコン。
- [03-voxel-sky.html](03-voxel-sky.html)：512×512高さマップの列投影式Voxel Space。ポリゴン・3Dエンジンなしで島と海を描き、リング飛行。PCは左右／ADで旋回、上下／WSで昇降。スマホは4方向アイコン。

3本とも独立HTML、Canvasのみ、外部依存なし。通常のゲーム画面に文字・数字・説明文なし（操作アイコン・記号のみ）。

**原理と限界**：2作目は正式な3D Gaussian Splattingの再現ではなく、公開情報から着想を得た点群・ピクセルスプラット風の独自描画です。作者の非公開コードや性能を再現したとは主張しません。3作目は高さマップ前方投影であり、完全な汎用3Dではありません。機能試作のため音・スコア保存なし。

**QA**：Chromium PC 1280×720、スマホ縦390×844、横844×390、3作品×3画面で操作・描画確認。JavaScript例外なし、文字DOMなし。1作目のアイテム取得、2作目の花の点灯、3作目の最初のリング通過を確認。実端末の長時間試遊は未実施。
