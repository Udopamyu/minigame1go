# 列島ブレイク

実データの日本に隕石・怪獣・分断を仕掛け、インフラ・人口・企業がどう動くかを1年分見届けるドット絵シミュレーター。

- 起動：`games/rettou-break/index.html` をローカルHTTPサーバー経由で開く（データを `fetch` で読むため、ファイルを直接開くと読み込めない）。
- 公開URL：https://udopamyu.github.io/minigame1go/games/rettou-break/
- 1プレイ：作戦づくり＋実行演出（約12秒）＋1年のシミュレーション（約60秒）＋結果。

## 遊び方

1. **観察**：拡大すると実際の地形が細かく描き直される。レイヤー（地形・夜景・電力・物流・交通/空路・企業・人口増減）を切り替えて見る。
2. **作戦（最大3回）**
   - 隕石：タップで落下地点。半径10/25/50km。
   - 怪獣：なぞった進路が海峡になる。幅8/16km。
   - 分断：指で囲み、ドラッグで海へ動かして島にする（陸地と重なる位置には置けない）。
3. **実行**：落下地点の街並み（大都会・市街地・住宅地・田園・山あい・港町・海上）のカットインのあと、地図上で被害が起きる。カットインはタップでスキップ。
4. **1年間**：避難・転出・帰還、停電、物流の迂回、バイパス・新しい町・施設や企業の移転、首都機能の移転。島や孤立地域は、残った人数で橋・海底トンネル・フェリー・空港・発電所が決まる。自動カメラが出来事に寄る（地図に触ると手動、ボタンで戻る）。
5. **結果**：ランクと称号、新しくできたもの・移ったものの一覧、都道府県ごとの人口増減、架空の住人1人の「その後の物語」、結果テキストのコピー。地図は「線 ON/OFF」「変化だけ表示」「被害前の地図」で切り替えられる。

## 復興の目安（島・孤立地域）

| 残った人数 | 作られるもの |
| --- | --- |
| 1万人以上 | フェリー（7日目） |
| 5万人以上・空港なし | 新空港（約3〜4か月） |
| 20万人以上・すき間25km以内 | 大橋 |
| 100万人以上・60km以内 | 海底トンネル |
| 800万人以上・160km以内 | 連絡トンネル |

島の電力は電源船（数日）→ 島内の火力発電所（30日目に決定）で回復する。

## データ

| ファイル | 中身 | 出典 |
| --- | --- | --- |
| `terrain.png` | 1km格子の標高（R,G）と海岸からの距離（B） | 国土地理院 標高タイル（dem_png z8）、Natural Earth |
| `info.png` | 都道府県・湖（R）、川（G）、人口密度（B） | 国土数値情報（行政区域、1kmメッシュ人口2020）、Natural Earth |
| `rivers.json` | 標高から計算した川の線 | 国土地理院 標高タイルから算出 |
| `world.json` | 高速道路・新幹線のグラフ、空港107、主要発電所98、港・物流拠点、都道府県別時価総額上位2社（94社） | 国土数値情報（高速道路N06-22・鉄道N02-22・空港C28-21）、Global Power Plant Database（WRI）、時価総額は2026-11-19時点（Yahoo!ファイナンス）、本店所在地はJ-LiC |

- 原発の稼働状況は2026年11月時点。放射性物質の拡散は扱わない。
- 企業は公開情報をもとに配置しただけで、移転などの動きは架空。「その後の物語」の人物もフィクション。
- `tools/` は地形・インフラデータを作ったスクリプトを制作時のまま保存したもの（パスは `work/` に置き換え）。元データのダウンロードは各提供元から行う。企業データの取得スクリプトは含めていない。
